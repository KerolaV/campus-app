# campus-app
Campus App on ammttikorkeakoulu opiskelijoille tarkoitettu sovellus.

Ominaisuudet

- Tulevien opiskelijatapahtumien tarkastelu
- Tapahtumiin ilmoittautuminen
- Omien tapahtumien lisääminen suosikkeihin
- Tapahtumien osallistujamäärä
- Tapahtumien kalenteri integraatio
- Tapahtumien sijaintitiedot
